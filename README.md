# 부활 복음 탐험대 ✝️

주일학교 아이들이 복음의 메시지를 정확하게 알고 기억할 수 있도록 돕는 활동 웹사이트입니다.

서버나 검색 기능 없이 링크만 열면 바로 사용할 수 있는 정적 웹페이지 한 장(`index.html`)으로 되어 있어요. 휴대폰·태블릿·컴퓨터 어디서나 동작합니다.

## 복음 내용

**부활 책자**를 바탕으로, 예수님의 **부활**을 중심으로 복음을 배웁니다. 부활 책자 7장 구조:

1. **부활 – 모든 사람이 믿을 만한 증거**
2. **부활로 성경의 모든 말씀을 믿는 것이다**
3. **이 세상은 어둠이다** (죄)
4. **복음** — 죽고 부활하신 예수님이 우리의 주인 되신 것
5. **죄는 예수님을 믿지 않는 것이다** (요 16:9)
6. **회개하고 복음을 믿으라!**
7. **부활의 주께 굴복하라!**

## 활동 소개

1. **📖 복음 이야기** — 부활 책자 7장을 한 장씩 넘기며 배우기
2. **💗 부활의 보화** — 부활에서 흘러나오는 14가지 보화와 그 말씀(성경 구절)
3. **🙏 주기도문** — 주기도문을 줄마다 단어를 가려 가며 외우기
4. **✨ 말씀 암송 게임** — 부활 복음의 핵심 말씀 외우기 (요 16:9, 롬 14:9, 고전 15:17 등)
5. **🎵 찬양 외우기** — "예수는 역사다" 가사를 절별로 외우기 (유튜브 영상 링크 포함)
6. **❓ 복음 퀴즈** — 부활 책자·찬양 내용 15문제 3지선다
7. **🃏 짝 맞추기** — 부활의 보화와 성경 구절 짝짓기 카드 게임
8. **🧩 순서 맞추기** — 부활 책자 7장을 순서대로 배열하기

## 웹사이트로 올리는 방법 (GitHub Pages)

1. 이 저장소의 **Settings → Pages**로 이동
2. **Source**에서 `Deploy from a branch` 선택
3. **Branch**를 `main`(폴더는 `/ (root)`)으로 선택하고 **Save**
4. 잠시 후 `https://norlgia.github.io/sundayschoolyouth/` 주소로 접속하면 끝!

인터넷 없이 쓰려면 `index.html` 파일을 태블릿이나 컴퓨터에 저장해서 그냥 열어도 됩니다.

> 성경 구절 본문은 교회에서 쓰시는 성경 번역본에 맞게 자유롭게 수정할 수 있어요.
