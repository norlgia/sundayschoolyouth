# 복음 탐험대 🌈

주일학교 아이들이 복음의 메시지를 정확하게 알고 기억할 수 있도록 돕는 활동 웹사이트입니다.

서버나 검색 기능 없이 링크만 열면 바로 사용할 수 있는 정적 웹페이지 한 장(`index.html`)으로 되어 있어요. 휴대폰·태블릿·컴퓨터 어디서나 동작합니다.

## 활동 소개

**다섯 가지 색깔 복음(말씀 없는 책)** 구조로 되어 있어서, 아이들이 색깔만 기억해도 복음 전체를 떠올릴 수 있습니다.

| 색깔 | 의미 | 대표 구절 |
|---|---|---|
| 👑 금색 | 하나님의 사랑과 천국 | 요한복음 3:16 |
| 💔 검정색 | 모든 사람의 죄 | 로마서 3:23 |
| ✝️ 빨간색 | 예수님의 십자가와 부활 | 로마서 5:8 |
| 🕊️ 흰색 | 죄 용서, 하나님의 자녀 | 요한복음 1:12 |
| 🌱 초록색 | 자라나는 믿음 | 베드로후서 3:18 |

포함된 활동 5가지:

1. **📖 복음 이야기** — 색깔 카드를 넘기며 복음 이야기와 성경 구절 읽기
2. **✨ 말씀 암송 게임** — 단어를 하나씩 가려 가며 말씀 외우기
3. **❓ 복음 퀴즈** — 10문제 3지선다 퀴즈, 즉시 피드백과 점수
4. **🃏 색깔 짝 맞추기** — 색깔과 의미를 짝짓는 카드 뒤집기 게임
5. **🧩 복음 순서 맞추기** — 복음 이야기 5단계를 순서대로 배열하기

## 웹사이트로 올리는 방법 (GitHub Pages)

1. 이 저장소의 **Settings → Pages**로 이동
2. **Source**에서 `Deploy from a branch` 선택
3. **Branch**를 `main`(폴더는 `/ (root)`)으로 선택하고 **Save**
4. 잠시 후 `https://norlgia.github.io/sundayschoolyouth/` 주소로 접속하면 끝!

인터넷 없이 쓰려면 `index.html` 파일을 태블릿이나 컴퓨터에 저장해서 그냥 열어도 됩니다.
